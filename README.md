# TP1 - Mon assistant de révision Python

## Présentation
Ce projet contient un programme Python `main.py` qui sert d'assistant de révision.

## Versions V1 à V4
* **V1** : Message initial de bienvenue, créé localement.
* **V2** : Ajout du prénom de l'utilisateur, puis premier push vers GitHub.
* **V3** : Ajout de la matière à réviser, puis récupération avec git pull.
* **V4** : Ajout de la durée de révision sur le PC, puis nouveau git push.

## Comment exécuter le programme
1. Ouvrez le dossier `tp_git_python` dans VS Code et cliquez sur `main.py`.
2. Cliquez sur le bouton de lecture en haut à droite.
3. Suivez les instructions dans le terminal et validez avec **Entrée**.

## Commandes Git utilisées
* `git init` : Initialiser le dépôt local.
* `git add` : Ajouter les fichiers modifiés.
* `git commit` : Enregistrer les modifications avec un message.
* `git push` : Envoyer les commits sur GitHub.
* `git pull` : Récupérer les modifications depuis GitHub.
